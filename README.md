# Big Daddy Junk Removal demo

Standalone Next.js 16 App Router demo for Big Daddy Junk Removal, Wauwatosa, WI.

## Verified content used

- Public business listing: [Nextdoor](https://nextdoor.com/pages/big-daddy-junk-removal-wauwatosa-wi/)
- Phone: `414-600-9705`
- Address: `4543 N 100th St, Wauwatosa, WI 53225`
- Services: cleanouts, demo removal, appliance removal, hot tub removal, outdoor appliance/metal pickup, and small-to-medium tree cut-up/removal.
- 18-yard dump trailer and fill-based estimate language are taken from the owner's public listing; no price is stated.
- The exact current Big Daddy Junk Haul logo is used from the business's public Nextdoor listing.

## Image provenance

The logo and all photography in `public/source-assets/` were downloaded from the business's current public [Nextdoor listing](https://nextdoor.com/pages/big-daddy-junk-removal-wauwatosa-wi/). The homepage hero is an actual load in the business's dump trailer, not stock or generated imagery.

## Commands

```bash
npm install
npm run lint
npm run typecheck
npm run build
npm run qa
```

This is intentionally local-only: no repository, deployment, domain, or form submission is configured.
