# Big Daddy Junk Removal demo

Standalone Next.js 16 App Router demo for Big Daddy Junk Removal, Wauwatosa, WI.

- Public business listing: [Nextdoor](https://nextdoor.com/pages/big-daddy-junk-removal-wauwatosa-wi/)
- Phone: `414-600-9705`
- Address: `4543 N 100th St, Wauwatosa, WI 53225`
- Services: cleanouts, demo removal, appliance removal, hot tub removal, outdoor appliance/metal pickup, and small-to-medium tree cut-up/removal.
- 18-yard dump trailer and fill-based estimate language are taken from the owner's public listing; no price is stated.
- No official Big Daddy logo was found in public research. The site uses a provisional typographic wordmark only; no invented icon or brand mark is presented.
